##Session 1 — Choosing My Startup Idea

**What I worked on:**
I started by brainstorming startup ideas with ChatGPT for my BSAD 281 project. I wanted to create something that would be useful for university students but also simple enough for me to build as a beginner.
After considering different ideas, I decided on MatchNstudy, a website that helps university students find study partners based on their courses, schedules, and study preferences.
**How I used AI:**
I used ChatGPT to help brainstorm ideas and understand how my startup could work. I also asked for help breaking down the project instructions into smaller steps because I had never built a website using GitHub before.
**What I learned:**
I learned that a startup idea does not have to be complicated to solve a real problem. I also learned that AI can help me organize my ideas and understand technical steps that I would normally find confusing.
**Reflection:**
I chose MatchNstudy because I could relate to the problem myself as a university student. I wanted my project to be something that could potentially help students at StFX.
##Session 2-Setting Up GitHub and Codespaces 

**What I worked on:**
After choosing my startup idea, I created a public GitHub repository called MatchNstudy. I then opened GitHub Codespaces so I could start building my website. Since I had very little experience with GitHub, I had to learn how to navigate the platform and organize my files.
**How I used AI:**
I used ChatGPT to guide me through setting up my repository and Codespaces. It explained where to click and how to complete each step. I also learned how GitHub Copilot could help me write code for my website.
**Challenges I Faced:**
One challenge was understanding the difference between GitHub, Codespaces, and GitHub Pages. At first, I wasn't sure what each one was used for. I learned that GitHub stores my project files, Codespaces provides an online coding environment, and GitHub Pages publishes my website.
**What I learned:**
I learned how to create a repository and use cloud-based development tools. This helped me understand how technology makes it possible to start a project without needing expensive software or equipment.
**Reflection:**
Setting up GitHub was confusing at first, but following the instructions step by step made it easier. I felt more confident once I had everything ready to start building MatchNstudy.
##Session 3- Building my Website and GitHub Copilot

 **What I worked on:**
During this session, I started building the MatchNstudy website using GitHub Codespaces and GitHub Copilot. My goal was to create a simple website where university students could look for study partners based on their courses, schedules, and study preferences.
I worked with three main files: index.html, style.css, and script.js. These files were used to create the website's structure, appearance, and interactive features.
**How I used AI:**
I used GitHub Copilot to help generate code for my website. I described what I wanted MatchNstudy to do and used the AI-generated code as a starting point. I also used ChatGPT to help me understand the steps involved in building the website.
**Challenges I faced:**
Since I did not have much experience coding, understanding how the different files worked together was challenging. I also had to learn how to make changes without affecting other parts of the website.
**What I learned:**
I learned that HTML creates the structure of a website, CSS controls how it looks, and JavaScript adds interactive features. I also learned how AI can help someone with limited coding experience build a working prototype.
**Reflecion:**
Building the website helped me see how my startup idea could become something real. Although the current version uses example student profiles rather than real accounts, it demonstrates how MatchNstudy could help students find study partners.
##Session 4- testing and Publishing MatchNstudy

**What I worked on:**
During this session, I focused on getting my MatchNstudy website published so other people could access it. After creating the website in GitHub Codespaces, I used GitHub Pages to make it available online.
I checked that the website opened through the public link and that the design and main features were visible.
**How I used AI:**
I used ChatGPT to help me understand how to publish my website through GitHub Pages. I followed the instructions to configure the repository settings and publish the website.
**Challenges I faced:**
One challenge was understanding how to connect my GitHub repository to GitHub Pages. I had to learn how the main branch and root folder were used to publish the website.
**What I learned:**
I learned how to publish a website online using GitHub Pages and how changes to my project files can be reflected on the public website.
**Reflection:**
Seeing MatchNstudy published online was one of the most rewarding parts of the project. I started with an idea and used AI and cloud technology to create a website that demonstrates how students could find study partners.
